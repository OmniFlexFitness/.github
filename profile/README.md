From our e-commerce storefront to our internal tooling, our engineering team builds software that keeps the organization running at peak performance.

## 🚀 Featured Repositories

### [OmniTask](https://github.com/OmniFlexFitness/OmniTask)
> **Our most actively developed project** — a full-featured, AI-powered project & task management web application.

OmniTask is an **Angular** application backed by **Firebase** and **Google Cloud** that enables teams to manage projects, tasks, assignees, and deadlines in one place. Key highlights include:

- 📋 **Project & Task Management** — Create projects, assign tasks, set due dates, and track progress through a rich dashboard
- 👥 **User Groups** — Bundle teammates into reusable groups for bulk assignment across projects and tasks
- 🗂️ **My Tasks Dashboard** — A personal view with KPI cards, a status donut, completion gauges, upcoming deadlines, and a self-assign queue for unassigned work
- 🔄 **Drag-and-Drop** — Reorder project groups with localStorage-backed persistence
- 🔍 **Semantic Search** — Powered by Vertex AI embeddings via the `firestore-vector-search` extension — no third-party search engine needed
- 🤖 **AI Integrations** — MCP servers for Angular CLI, Firebase, Google Cloud, BigQuery, Cloud SQL, AlloyDB, Spanner, GitHub, Google Drive, and Google Maps; Firebase Extensions for email, image resize, speech-to-text, image OCR, and multimodal GenAI
- 📊 **Google Sheets Sync** — One-click export of personal task and project data to a live spreadsheet
- 🔒 **GDPR-Compliant** — Automated user-data deletion on account removal via the `delete-user-data` Firebase Extension
- 🚀 **Automated Deploy Previews** — Every pull request gets a live Firebase Hosting preview URL via GitHub Actions

**Stack:** Angular · TypeScript · Firebase (Firestore, Hosting, Extensions) · Google Cloud · Vertex AI · GitHub Actions

### [OmniFlex Shopify Theme](https://github.com/OmniFlexFitness/OmniFlex-Shopify-Theme)
> **The custom storefront theme** powering the OmniFlex Fitness e-commerce website.

This repository contains the Shopify theme that delivers the OmniFlex shopping experience. Key highlights include:

- 📱 **Responsive Design** — Fully optimized across desktop, tablet, and mobile
- 🧩 **Customizable Sections** — Drag-and-drop sections for easy admin customization
- 🎞️ **Infinite-Loop Slideshow** — Dynamic hero/banner component with smooth infinite scrolling
- 📢 **Announcement Bar** — Configurable bar for promotions and store updates
- ⚡ **Performance-Optimized** — Lazy-loaded images and reduced-motion accessibility support
- 🌐 **Cross-Browser Compatible** — Tested on all major browsers

**Stack:** Liquid · JavaScript · CSS · Shopify CLI

### [OmniTrivia](https://github.com/OmniFlexFitness/OmniTrivia)
> **A real-time multiplayer trivia web app** — think Kahoot! meets Trivia Crack.

OmniTrivia lets users host and join live trivia sessions. Players enter a game code to join an ongoing session and compete against each other in real time, combining the accessibility of Kahoot! with the engaging gameplay of Trivia Crack.

**Stack:** TypeScript · Angular
